# crates

The engine crates kitesurf used to patch at build time, now owned here: one Cargo workspace, every package prefixed `browser-` (the library names are unchanged, so no source line changed), sibling dependencies by path and version so each crate can be published, versions as pinned by the upstream release the series was cut from.

- Source of truth: this directory. The same changes also live as one commit per patch on the `kitesurf` branch of each aphrody-labs fork (parley, blitz, anyrender, taffy, stylo, boa, resvg, vello, ratatui-image, jpeg-encoder), cut from the exact upstream commit of the published crate (`.cargo_vcs_info.json`).
- `scripts/patches` and `scripts/get-patched-vendor-crates.mjs` remain only because the Bazel build still applies them (`bazel/rust/crates.bzl`); Bazel moves to this workspace next, then they are deleted.
- `FEATURES.md` is the feature matrix, generated by `tools/kitesurf-monorepo.ts matrix` of the browser repository, which also generated this layout.
